# 圆形屏 LVGL 显示示例

硬件：NV3003A，直径 1.8 英寸圆形屏，可视区为圆形，显存/逻辑分辨率为 360×360。
QSPI 与 Arduino 最新厂家初始化序列沿用原显示驱动。

## 模块

- components/display：QSPI、NV3003A 窗口/矩形刷新、背光。
- components/lvgl：从本地 Arduino 库复制的 LVGL 8.3.11 核心，配置位于 lv_conf.h。
- components/lvgl_port：20 行双 DMA 缓冲、同步 flush、LVGL 专属任务。
- components/ui_demo：圆弧进度、32 号中心百分比、运行时间及闪烁状态点，每秒更新；三条彩色圆环持续伸缩。
- main/main.c：初始化硬件并启动适配层，首帧由 LVGL 任务完成后点亮背光。

界面使用内置英文字体，中心百分比为演示数据，不代表传感器或电池读数。
重要内容集中在圆内，圆弧直径 320 像素，避免四角不可见区域。
内侧红、绿、蓝圆环直径分别在 120~140、156~176、192~212 像素间来回变化，
边框宽 4 像素，放大/缩小时间分别为 1.1、1.4、1.7 秒，错开启动以形成呼吸动画。
标题和底部文字放在圆环之外，中心百分比改为 Montserrat 32 号字体。

## 刷新与任务约定

两块 360×20×2 字节缓冲区均从内部 DMA RAM 分配，共 28,800 字节。
LVGL 内存池为 64 KiB，任务栈为 8 KiB，使用 esp_timer 单调时钟作为毫秒时基。
LV_COLOR_16_SWAP=1 统一产生高字节在前的 RGB565，flush 不再次交换字节。
每个区域仅发送一次 2Ah/2Bh 窗口，QSPI 首包带 32h+002C00h，
后续分包保持 CS 有效并仅发送像素，传输结束才调用 lv_disp_flush_ready。
当前同步方案的双缓冲不会实现 DMA 与绘制并行，后续可独立升级为异步刷新。

LVGL 对象操作和写屏只由 LVGL 任务执行；其他任务通过消息队列提供数据，
再在 LVGL 定时器/事件回调中更新对象。不要同时启动原纯色轮播任务。
触摸尚未接入；此示例自动运行，不需要触摸操作。

## 验证

在已加载 ESP-IDF 5.5.4 环境的终端执行 idf.py build。
烧录：idf.py -p COM71 flash monitor（串口以当前设备为准）。
首帧完成应出现 LVGL_PORT 的 first frame ready 日志。
检查百分比和时间每秒更新，三条圆环持续平滑放大/缩小，红绿蓝颜色正常且无错行或重复区域。
此次只做编译验证，实际显示效果需要硬件烧录确认。
